# Regarde!

https://naq26.kattis.com/contests/naq26/problems/regarde

Time limit: 1000 ms, memory limit: 2048 MB

Monroe is in charge of Busan Library. Busan Library is known for its prestige but also its especially quiet environment.

One day, a group of rowdy computer programmers comes in and starts disturbing the peace, and Monroe has to step in to hush them. Depending on how severely the group is disturbing the peace, Monroe will hush with a specific intensity. Specifically, a hush of intensity $n$ will cause Monroe to say shh... with $n+1$ h’s.

Given the desired intensity of Monroe’s hush, determine exactly how Monroe will hush the programmers.

## Input

The first line of input contains a single integer $t$ $(1 \le t \le 50)$, which is the number of test cases.

The descriptions of $t$ test cases follow. Each test case consists of a single line containing a single integer $n$ $(1 \le n \le 50)$, which is the intensity of Monroe’s hush.

## Output

For each test case, output the exact hush that Monroe will make, one per line.

Sample Input 1

Sample Output 1

```
2
1
10
```

```
shh
shhhhhhhhhhh
```
